# On-Page SEO Findings — reviewkit.gutensuite.net

## Strengths
- Unique `<title>` per page, `Page | Reviewkit` pattern, healthy lengths.
- One `<h1>` per page; clean h2/h3 hierarchy.
- Internal links between home/features/pricing/docs; footer nav covers key pages.

## Issues
- **Identical meta description on all 7 pages** ("Show your Trustpilot reviews on WordPress. No API keys, no code, no slowdowns.") — no page-specific SERP copy.
- **No canonical tags anywhere** — combined with trailing-slash (500) and HTTP (200) duplicates, Google gets no canonicalization help.
- **No Open Graph or Twitter Card tags** — bare link previews on social/chat.
- Mobile menu lists Changelog twice.
