Install Reviewkit in a minute, straight from the WordPress plugin directory. Pick whichever way suits you.

## Modern Way

### Search on WordPress.org

Go to your **WordPress Dashboard → Plugins → Add Plugin** page. Click on the **Add Plugin** button, then search "reviewkit".

![Searching for reviewkit on the Add Plugin screen](https://reviewkit-data.gutensuite.net/wp-content/uploads/2025/11/image-4-1024x576.png)

### Activate the plugin

Go to the **Installed Plugins** page and activate the plugin.

![Activating Reviewkit on the Installed Plugins screen](https://reviewkit-data.gutensuite.net/wp-content/uploads/2025/11/image-3-1024x66.png)

That's how simple it is.

## Old Way

### Search on WordPress.org

Simply search **"Reviewkit Trustpilot"** on the WordPress.org [plugin directory](https://wordpress.org/plugins/) and find the following plugin.

![Reviewkit Trustpilot listed on WordPress.org](https://reviewkit-data.gutensuite.net/wp-content/uploads/2025/11/image-1024x454.png)

### Download the plugin

![Downloading the Reviewkit plugin](https://reviewkit-data.gutensuite.net/wp-content/uploads/2025/11/image-1-1024x488.png)

### Upload the plugin on your website

Go to your **WordPress Dashboard → Plugins → Add Plugin**. Click on the **Upload** button and upload the downloaded Reviewkit plugin.

![Uploading the Reviewkit plugin zip](https://reviewkit-data.gutensuite.net/wp-content/uploads/2025/11/image-2-1024x279.png)

### Activate the plugin

Go to the **Installed Plugins** page and activate the plugin.

That's it. Your Trustpilot reviews are now one Sync Reviews click away.
